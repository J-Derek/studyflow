# StudyFlow — Project Context

## Project Overview
StudyFlow is a modern student productivity web application designed to help university students manage academic assignments, organize study schedules, and track productivity.

## Core Roles
- **ChatGPT**: Software Architect, Product Manager, UI/UX Design Director, Technical Reviewer, QA Lead.
- **Antigravity (Agy)**: Lead Developer, Figma Implementation Agent, Full-Stack Engineer, QA & Vercel Deployment Agent.
- **21 (Owner)**: Product Owner & Final Decision-Maker.

## Collaboration Protocol
- ChatGPT delivers actionable tasks inside:
  ```
  BEGIN ANTIGRAVITY TASK
  [Instructions]
  END ANTIGRAVITY TASK
  ```
- Antigravity executes instructions, verifies work, updates local state files, and submits an execution report back to ChatGPT.
- Local project files (`project-context.md`, `current-status.md`, `decisions.md`, `execution-report.md`) preserve context across sessions.

## Target V1 Feature Scope
1. **Dashboard**: Welcome section, upcoming assignments, urgent tasks, overall progress.
2. **Assignment Management**: CRUD operations, completion toggle, priority, deadlines.
3. **Study Calendar**: Weekly view, deadline tracking, session planning.
4. **Focus Timer**: Configurable Pomodoro-style timer with start/pause/progress.
5. **Productivity Stats**: Completed vs. pending assignments and productivity metrics.

## Workflow Discipline
1. Visual direction & UX spec from ChatGPT.
2. Figma design creation & verification.
3. ChatGPT design review & approval.
4. Implementation, testing, verification, and execution reporting.
